# Параллельные алгоритмы приближённого поиска ближайших соседей (IVF и LSH)

Командный проект по ПП.  
Цель работы — реализовать с нуля последовательные и многопоточные версии двух популярных алгоритмов приближённого поиска ближайших соседей (**ANN** — *Approximate Nearest Neighbors*) в многомерных векторных пространствах и сравнить их по скорости, точности, потреблению памяти и масштабируемости.

## Реализованные алгоритмы

- **BruteForceIndex** — точный полный перебор по всем векторам. Используется как эталон (*Ground Truth*) для расчёта точности приближённых методов.
- **IVF (Inverted File Index)** — разбиение векторного пространства на кластеры методом `K-Means++` и поиск ближайших соседей только в `nprobe` ближайших ячейках.
- **LSH (Locality-Sensitive Hashing)** — проецирование векторов на случайные гиперплоскости (*SimHash*) с построением $L$ независимых хеш-таблиц.

## Технологии и особенности реализации

- **Язык:** Java 21 (без сторонних библиотек)
- **Многопоточность:** `ForkJoinPool` с настраиваемым числом потоков ($P \in \{1, 2, 4, 8\}$)
- **Метрика:** квадрат евклидова расстояния на L2-нормализованных векторах (эквивалентно косинусному сходству)
